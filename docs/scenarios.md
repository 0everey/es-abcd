# 场景说明

本仓库里的「场景」= **工程 / 创意 / 稳定** 三种生成模式模板。  
完整可复制文案见仓库根目录 [README.md](../README.md)。

| 你怎么说 | 内部模式名 | 适合 |
|----------|------------|------|
| 工程模式 | `engineering` | 做对、边界清、能落地 |
| 创意模式 | `creative-divergence` | 多方案、差异大 |
| 稳定模式 | `stable` | 贴现状、少翻车、能收口 |

每种模式 README 内各有 **5 组真实应用场景**（技能、道具、经济、任务、战斗等），复制后只改 `<项目根路径>` 即可测。
