# 接入价值（对内备忘）

> 本文给维护者写对外介绍时用。**用户请看 [开始试用.md](../开始试用.md) 与根目录 README。**

## 一句话

装 es-abcd，是给「人和 AI 做系统」三套可复制场景：工程 / 创意 / 稳定。

## 接入后能力

| 能力 | 说明 |
|------|------|
| 项目画像 | 识别空目录、Unity、Node、类 ES 等再决定怎么装 |
| 按情况接入 | 已装则刷新；禁止装进包自身 |
| 三种模式 | 做对 / 发散 / 保稳定 |
| 可复制场景 | README 内 15 组 |
| 适配清单 | 待办与边界 |
| 证据分层 | 不把静态通过说成发版通过 |

## 不要对外乱承诺

- 不是游戏引擎  
- 不是一键可玩可发版  
- 不要求必须先有旧 ES 大仓
