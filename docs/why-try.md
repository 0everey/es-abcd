# 为什么有人愿意接入（对外话术备忘）

## 一句话

装 es-abcd，不是多一个库，而是给「人和 AI 做系统」三套可复制考卷：工程 / 创意 / 稳定。

## 立刻能用的 B 面能力（接入后）

| 能力 | 人话 |
|------|------|
| 项目画像 | 先看你是空目录、Unity、Node 还是类 ES，再决定怎么装 |
| 按情况接入 | 已装过就刷新；装进自身会拦截 |
| 三种模式 | 做对 / 发散 / 保稳定，话术不同 |
| 15 组真场景 | 技能、道具、经济、任务、战斗…复制即测 |
| 适配清单 | 告诉你还要拍板什么 |
| 证据边界 | 不把「能聊」说成「已上线」 |

## 不该用来装的

- 伪装成游戏引擎  
- 承诺一键可玩可发版  
- 绑定必须先有旧 ES 大仓
