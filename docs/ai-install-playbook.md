# AI 一句话安装剧本（给 Agent）

## 用户可以说

> es-abcd 在 `<es-abcd根路径>`。请安装到项目 `<项目根路径>`，先分析再按情况接入，出适配清单，**全程用人话汇报**，路径都写绝对路径。

等价说法（**必须带用户真实绝对路径**）：

- 包在 `<es-abcd根路径>`，项目在 `<项目根路径>`，请安装并出清单  
- 把 ABCD 装进 `<项目根路径>`（包路径先向用户确认）  

未给路径：先问清两个绝对路径，再动手。禁止说「装到电脑上」这种含糊话。

## 固定步骤（不得跳）

1. **确认 es-abcd 包目录**（含 `get.ps1`、清单文件）  
2. **确认项目根绝对路径**（不能把 es-abcd 自身当业务项目，除非用户明确要求）  
3. **执行一键**（内部会先分析项目）：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "<es-abcd根路径>/get.ps1" -TargetRoot "<项目根路径>" -Force
```

顺序：项目画像 → 按类型调整 → 叠加安装 → 冒烟 → 适配清单。

4. **向用户回报（必须说人话）**  
   - 项目被识别成什么  
   - 装成了没有  
   - 画像 / 清单 / 回执的**绝对路径**  
   - 还要用户拍板的项  
   - 明确：不依赖旧 ES 宿主；运行时若没验要说「运行时未验」；不能说 PlayMode/发版已过  

## 禁止

- 手搓第二套核心  
- 未经授权改业务玩法代码  
- 用冒烟冒充运行时验收  
- 索取或写入 API Key  
- 假设必须依赖原生 ES 大仓  

## 成功标准

| 项 | 期望 |
|----|------|
| 一键脚本 | 成功结束 |
| 日常入口 | 项目内已生成 |
| 冒烟 | 通过（静态） |
| 清单 | 已生成 |
| 身份 | 写明与 ES 独立/可选 |
